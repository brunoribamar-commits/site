# Nosso Casamento

Site para organizar o casamento, montado a partir do PDF "Casamento" (orçamentos e compras).

Abra `index.html` no navegador. Não precisa instalar nada.

- **Resumo**: contagem regressiva, gasto fechado e previsto em relação ao orçamento, próximas tarefas.
- **Fornecedores**: fotografia e vídeo, atividades, assessoria e animadores, com links, status do orçamento, valor e observações.
- **Compras**: itens de decoração e presentes de madrinhas e padrinhos, com link da loja, quantidade, preço e marcação de comprado.
- **Tarefas**: cronograma sugerido, editável.
- **Convidados**: lista por grupo com confirmação de presença.

Os dados ficam salvos no navegador (localStorage). Para levar para outro aparelho, use
"Configurações e backup" no rodapé: copie o backup em um aparelho e cole no outro.

Para publicar com GitHub Pages: Settings → Pages → Deploy from a branch → escolha a branch e a pasta `/`.
